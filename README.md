# DHL MATH 홈페이지

고등 수학 DHL MATH의 홈페이지입니다. 빌드 과정 없이 파일 그대로 GitHub Pages에서 열립니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 머리말·바닥글 등 모든 화면의 틀 |
| `css/style.css` | 디자인 (색, 글꼴, 배치) |
| `js/data.js` | **학원 정보와 예시 데이터** — 연락처·주소는 여기서 바꿉니다 |
| `js/store.js` | 데이터 저장 (지금은 브라우저 저장, 나중에 데이터베이스로 교체) |
| `js/app.js` | 화면 구성과 버튼 동작 |

## 화면

홈 · 강좌 · 강의실(유튜브 연결) · 성적 관리 소개 · 공지 · 학생 · 학부모 · 상담 신청 · 선생님 관리(바닥글 링크)

## 주의

- 이 저장소는 공개됩니다. **학생 실명·성적·연락처를 파일에 넣지 마세요.**
- 학생·학부모 화면은 가상 학생으로 만든 미리보기입니다.
- 선생님 관리 화면은 아직 잠겨 있지 않으며, 바꾼 내용은 그 브라우저에만 저장됩니다.
- 로그인·학생별 자료·상담 접수는 데이터베이스(Supabase 예정)를 연결한 뒤 열립니다.
